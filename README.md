# DB Application

一个面向个人用户的本地 MySQL 可视化管理与数据工作台。

系统目标是让不同用户登录后进入自己的个人工作台，通过 GUI 管理属于自己的数据库、数据表和表数据，并查看用户级、数据库级、表级统计信息。项目强调前后端分离、统一视觉风格、双 Token 鉴权、用户数据隔离、SQL 安全和操作可追踪。

## 技术栈

- 前端：Vue 3、Vite、TypeScript、Element Plus
- 后端：Node.js、Express、TypeScript
- 数据库：MySQL
