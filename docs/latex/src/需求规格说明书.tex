\hypertarget{ux9879ux76eeux76eeux6807}{%
\subsection{1. 项目目标}\label{ux9879ux76eeux76eeux6807}}

本项目是一个面向个人用户的本地 MySQL 可视化 DBMS
工作台。用户登录系统后进入个人工作台，通过统一风格的 GUI
完成数据库对象管理、表结构设计、数据增删改查、GUI
查询、事务操作、视图管理、索引管理、约束管理和统计分析。

系统不把 MySQL
账号密码暴露给前端。前端提交结构化操作请求，后端完成鉴权、权限校验、参数校验、SQL
构造、数据库执行、精确错误归类和审计记录。

\hypertarget{ux529fux80fdux8303ux56f4}{%
\subsection{3. 功能范围}\label{ux529fux80fdux8303ux56f4}}

系统包含以下功能：

\begin{itemize}
\tightlist
\item
  注册、登录、双 Token 会话、退出登录。
\item
  个人工作台首页。
\item
  用户资料与偏好设置。
\item
  主色调快速切换。
\item
  用户数据库完整管理。
\item
  表、字段、主键、外键、唯一约束、检查约束、默认值、非空约束管理。
\item
  索引管理。
\item
  视图管理。
\item
  表数据增删改查。
\item
  GUI 化 \texttt{SELECT} 查询。
\item
  事务会话管理。
\item
  用户级、数据库级、表级统计。
\item
  操作日志和审计追踪。

\hypertarget{ux8ba4ux8bc1ux4e0eux4f1aux8bddux9700ux6c42}{%
\subsection{4.
认证与会话需求}\label{ux8ba4ux8bc1ux4e0eux4f1aux8bddux9700ux6c42}}

\hypertarget{req-auth-001-ux7528ux6237ux6ce8ux518c}{%
\subsubsection{REQ-AUTH-001
用户注册}\label{req-auth-001-ux7528ux6237ux6ce8ux518c}}

系统必须允许用户通过昵称和密码注册。注册成功后，系统生成 10 位登录账号。

验收标准：

\begin{itemize}
\tightlist
\item
  昵称去除首尾空格后长度为 2 到 20。
\item
  密码长度为 8 到 16。
\item
  密码同时包含英文字母和数字。
\item
  密码只保存 bcrypt 哈希。
\item
  注册成功返回登录账号和展示昵称。
\item
  注册响应不返回密码明文和密码哈希。
\end{itemize}

\hypertarget{req-auth-002-ux7528ux6237ux767bux5f55}{%
\subsubsection{REQ-AUTH-002
用户登录}\label{req-auth-002-ux7528ux6237ux767bux5f55}}

系统必须允许用户使用 10 位账号和密码登录。

验收标准：

\begin{itemize}
\tightlist
\item
  账号必须为 10 位数字。
\item
  登录失败统一返回``账号与密码不匹配''。
\item
  登录成功签发 Access Token 和 Refresh Token。
\item
  Access Token 返回给前端。
\item
  Refresh Token 写入 HttpOnly Cookie。
\item
  登录成功写入审计日志。
\end{itemize}

\hypertarget{req-auth-003-ux4f1aux8bddux5237ux65b0}{%
\subsubsection{REQ-AUTH-003
会话刷新}\label{req-auth-003-ux4f1aux8bddux5237ux65b0}}

系统必须支持通过 Refresh Token 刷新 Access Token。

验收标准：

\begin{itemize}
\tightlist
\item
  Refresh Token 只用于刷新会话。
\item
  Refresh Token 服务端只保存哈希。
\item
  刷新成功执行 Refresh Token Rotation。
\item
  被替换的 Refresh Token 再次使用时，系统撤销同一 token family。
\end{itemize}

\hypertarget{req-auth-004-ux9000ux51faux767bux5f55}{%
\subsubsection{REQ-AUTH-004
退出登录}\label{req-auth-004-ux9000ux51faux767bux5f55}}

系统必须支持用户主动退出登录。

验收标准：

\begin{itemize}
\tightlist
\item
  当前 Refresh Token 被撤销。
\item
  Refresh Token Cookie 被清除。
\item
  前端丢弃 Access Token。
\item
  退出操作写入审计日志。
\end{itemize}

\hypertarget{req-row-003-ux4feeux6539ux6570ux636e}{%
\subsubsection{REQ-ROW-003
修改数据}\label{req-row-003-ux4feeux6539ux6570ux636e}}

系统必须支持修改单行和批量修改。

验收标准：

\begin{itemize}
\tightlist
\item
  用户在网页表格中直接修改单元格时，修改内容先进入前端草稿态，不得立即写入数据库。
\item
  被修改的行必须展示``待更新''状态，并在行旁提供``更新/提交''按钮。
\item
  用户点击对应行的``更新/提交''按钮后，前端才调用后端修改接口。
\item
  用户可以取消单行草稿修改，取消后恢复为服务端最新数据。
\item
  单行更新优先使用主键定位目标行；无主键表必须使用服务端生成的稳定行定位策略或禁止行内编辑。
\item
  修改条件必须来自 GUI 条件构造器。
\item
  不允许无条件修改。
\item
  修改前进行影响行数预估。
\item

\hypertarget{ux9519ux8befux63d0ux793aux9700ux6c42}{%
\subsection{13.
错误提示需求}\label{ux9519ux8befux63d0ux793aux9700ux6c42}}

\hypertarget{req-error-001-ux7cbeux786eux9519ux8befux6a21ux578b}{%
\subsubsection{REQ-ERROR-001
精确错误模型}\label{req-error-001-ux7cbeux786eux9519ux8befux6a21ux578b}}

系统必须为所有失败操作返回精确错误信息。

验收标准：

\begin{itemize}
\tightlist
\item
  前端无法连接后端时显示网络连接错误。
\item
  后端无响应时显示请求超时。
\item
  后端业务校验失败时显示字段级错误。
\item
  数据库连接失败时显示数据库连接错误。
\item
  数据库执行失败时返回 MySQL
  错误号、SQLSTATE、数据库错误消息、对象名、字段名、约束名。
\item
  批量操作失败时返回失败行号、失败字段、失败原因。
\item
  错误响应必须包含 \texttt{traceId}。
\end{itemize}

\item
  删除表必须输入表名确认，不能关闭。
\item
  删除字段必须输入字段名确认，不能关闭。
\item
  批量修改达到阈值时必须确认。
\item
  批量删除达到阈值时必须确认。
\item
  触发外键级联影响时必须展示影响分析。
\item
  用户偏好中保存中风险操作确认开关。
\item
  弹窗支持``本类中风险操作不再提示''，该选择写入用户偏好。
\end{itemize}

\hypertarget{ux975eux529fux80fdux4e0eux5bb9ux91cfux9650ux5236ux9700ux6c42}{%
\subsection{16.
非功能与容量限制需求}\label{ux975eux529fux80fdux4e0eux5bb9ux91cfux9650ux5236ux9700ux6c42}}

\hypertarget{req-limit-001-ux5bb9ux91cfux9650ux5236}{%
\subsubsection{REQ-LIMIT-001
容量限制}\label{req-limit-001-ux5bb9ux91cfux9650ux5236}}

系统必须对用户资源、数据库对象、查询复杂度和批量操作设置明确上限。

验收标准：

\begin{itemize}
\tightlist
\item
  容量限制由服务端配置集中管理，前端只负责展示提示。
\item
  创建数据库、创建表、上传资源、执行查询和批量写操作前均执行限制校验。
\item
  超过容量限制时返回
  \texttt{LIMIT\_EXCEEDED}，并展示具体超限项和当前上限。
\item
  查询类操作必须限制最大返回行数、最大查询耗时、最大 JOIN
  数、最大子查询深度。
\item
  写操作必须限制批量行数和最大影响行数。
\item
  文件资源必须限制单文件大小、单用户资源总量和允许 MIME 类型。
\end{itemize}
